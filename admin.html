Segments de la roue

Icône Description Poids Stock initial

Le poids détermine la probabilité relative du segment parmi les lots encore en stock (deux segments à 100 ont la même chance ; un segment à 50 a deux fois moins de chance).

Le stock initial est optionnel (vide = illimité). Le stock restant se décrémente à chaque gain et se reconstitue avec « Réinitialiser les stocks ».

Mode personnalisé : réglez chaque couleur de la palette manuellement.

Le mode duo garde la palette du thème mais n'en alterne que deux teintes : meilleure lisibilité à trois mètres. Les filets et le pointeur restent dorés.

Choisir un thème ne l'applique pas : « Appliquer le thème » l'enregistre sur ce poste et met la roue à jour immédiatement.

Sécurité

Verrou PIN de ce poste

Le code PIN empêche un visiteur d'ouvrir l'administration par erreur. Ce n'est pas un mécanisme de sécurité fort : il est stocké uniquement sur ce poste, jamais dans la configuration exportée. Un PIN oublié se contourne en vidant les données du site dans le navigateur.

Sauvegarde & distribution

Configuration du poste

« Enregistrer » stocke la configuration localement : elle reste disponible hors-ligne sur cet ordinateur. Pour changer la configuration par défaut vue par tout le monde, exportez le fichier puis remplacez config.json dans le dépôt GitHub.
