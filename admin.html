Segments (lots à gagner)

Icône Description Poids Stock initial

Le "poids" détermine la probabilité relative du segment parmi les lots encore en stock (ex : deux segments à poids 100 ont la même chance ; un segment à 50 a deux fois moins de chance qu'un segment à 100).

Le "stock initial" est optionnel (laisser vide = illimité). Le stock restant se décrémente automatiquement à chaque gain sur la roue, et se reconstitue avec le bouton ci-dessous.

Sécurité

Le code PIN empêche un visiteur du salon d'ouvrir l'administration par erreur. Ce n'est pas un mécanisme de sécurité fort : il est stocké uniquement sur ce poste, jamais dans la configuration exportée. Un PIN oublié se contourne en vidant les données du site dans le navigateur.

Sauvegarde & distribution

« Enregistrer sur ce poste » stocke la configuration localement (localStorage) : elle reste disponible hors-ligne sur cet ordinateur, y compris après réinstallation de l'application. Pour changer la configuration par défaut vue par tout le monde sur le site public, exportez le fichier puis remplacez config.json dans le dépôt GitHub.
