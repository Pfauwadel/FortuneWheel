Comprendre et installer l'application

Comment fonctionne la roue, comment installer l'application pour qu'elle marche sans connexion sur un poste de stand, et comment régler lots, thème et sécurité depuis l'administration.

01 · Vue d'ensemble

Trois pages, un seul site

L'application est un site 100 % statique (aucun serveur, aucune base de données) composé de trois pages autonomes. Elles partagent la même configuration.

index.html

Page de présentation. Sert de vitrine et de point d'entrée vers la roue, l'administration et ce guide.

wheel.html

L'écran public affiché sur le stand : c'est cette page qu'on installe et qu'on laisse ouverte toute la journée.

admin.html

Réglage des lots, du thème, des animations et de la sécurité, avec un aperçu de la roue en direct.

Aucune donnée ne part vers un serveur externe : tout est lu et écrit dans le navigateur du poste (voir Configuration & sauvegarde).

02 · Installation

Installer l'application hors-ligne

L'application est une PWA (Progressive Web App) : une fois installée sur un poste, elle se lance comme un programme local, avec sa propre fenêtre, et continue de fonctionner sans connexion internet.

Étape obligatoire avant toute installation : ouvrir wheel.html au moins une fois en étant connecté à internet, pour que le navigateur télécharge et mette en cache tous les fichiers de l'application.

Installation en un clic

Si votre navigateur le permet, le bouton ci-dessous lance l'installation directement :

Ce navigateur ne propose pas d'installation en un clic ici (ou l'application est déjà installée) — utilisez les instructions manuelles ci-dessous selon votre navigateur.

Sur iPhone/iPad, Safari n'offre pas de bouton d'installation automatique : suivez les étapes « Safari (iPhone / iPad) » ci-dessous.

✓ L'application est déjà installée sur cet appareil.

Instructions manuelles par navigateur

Chrome / Edge (Windows, macOS)
  1. Ouvrir wheel.html (ou la page d'accueil).
  2. Cliquer sur l'icône d'installation ⊕ dans la barre d'adresse.
  3. Confirmer « Installer ».
Chrome (Android)
  1. Ouvrir la page dans Chrome.
  2. Menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
  3. Confirmer.
Safari (iPhone / iPad)
  1. Ouvrir la page dans Safari.
  2. Bouton Partager (carré avec flèche) en bas de l'écran.
  3. « Sur l'écran d'accueil » → « Ajouter ».
Firefox
  1. Firefox ne propose pas d'installation PWA complète sur tous les systèmes.
  2. Utilisez plutôt Chrome ou Edge pour un vrai mode hors-ligne installé.
  3. Sinon, un simple raccourci/onglet épinglé reste possible.

Après installation

L'application s'ouvre depuis son icône, dans sa propre fenêtre, sans barre d'adresse. Elle fonctionne ensuite sans connexion : le service worker (sw.js) sert les fichiers depuis le cache local dès que le réseau est indisponible, et se met à jour automatiquement dès qu'une connexion est de nouveau disponible.

03 · Écran public

Ce que voient les visiteurs

wheel.html affiche la roue en plein écran : titre, roue animée, bouton « Tourner la roue », et un bandeau défilant listant les lots encore en jeu.

  • Tirage — le poids de chaque lot détermine sa probabilité relative parmi les lots encore en stock.
  • Stock — un lot avec un stock épuisé reste visible mais grisé, et ne peut plus être tiré.
  • Confettis & sons — activables/désactivables depuis l'administration, onglet « Animations ».
  • Mode attraction — après une période d'inactivité, le bouton pulse pour inciter les passants à jouer.

L'icône ⚙ en haut à droite ouvre l'administration — pensez à activer un verrou PIN si le poste est en libre accès.

04 · Administration

Régler la roue depuis admin.html

L'administration est organisée en onglets, avec un aperçu de la roue toujours visible à droite pendant la saisie (avant même d'enregistrer).

Lots

Chaque segment a une description, une icône, un poids (probabilité relative) et un stock initial optionnel (vide = illimité). La bibliothèque de goodies permet d'ajouter un lot préconfiguré en un clic. « Réinitialiser les stocks » remet tous les compteurs à leur valeur initiale, par exemple entre deux journées d'un même évènement.

Réglages

Titre affiché, texte au centre de la roue, nombre de tours min/max et durée d'affichage du lot gagné.

Thème

Dix palettes prédéfinies, ou génération automatique d'une palette harmonieuse à partir d'une seule couleur de marque. Le mode « Duo » alterne deux teintes sur la roue pour une meilleure lisibilité à distance ; le mode « Palette complète » alterne les six teintes du thème. « Appliquer le thème » est nécessaire pour l'enregistrer sur ce poste — choisir une carte ne suffit pas.

Animations

Confettis, sons synthétisés et mode attraction, chacun activable indépendamment.

Sécurité

Un code PIN local protège l'accès à l'administration sur un poste partagé. Il n'est jamais inclus dans config.json ni dans un export : c'est un verrou de confort, pas un mécanisme de sécurité fort. Un PIN oublié se contourne en vidant les données du site dans le navigateur (voir Dépannage).

05 · Configuration

Comment la configuration est stockée

config.json, dans le dépôt du site, est la configuration par défaut vue par n'importe qui ouvrant le site pour la première fois.

Toute modification faite dans admin.html est enregistrée dans le localStorage du navigateur utilisé : elle surcharge config.json sur cet appareil uniquement, et reste disponible hors-ligne après installation.

Pour changer la configuration par défaut vue par tout le monde : dans l'onglet « Sauvegarde » de l'administration, cliquer sur Exporter, puis remplacer config.json dans le dépôt (commit + push).

« Importer un fichier » permet de recharger une configuration exportée précédemment (par exemple pour dupliquer les réglages d'un poste sur un autre). « Réinitialiser » efface la surcharge locale et revient à config.json.

06 · Dépannage

Questions fréquentes

Une modification n'apparaît pas, même après rafraîchissement

Le service worker recharge automatiquement dès qu'une nouvelle version est détectée sur le réseau. Si l'écran reste figé, vérifiez la connexion internet du poste : sans réseau, c'est la dernière version mise en cache qui s'affiche, ce qui est le comportement normal du mode hors-ligne.

J'ai oublié le code PIN de l'administration

Le PIN est stocké uniquement dans le navigateur de ce poste. Pour le retirer : effacer les données du site (Réglages du navigateur → Confidentialité → Données de wheel.html / admin.html), ce qui remet aussi la configuration locale à config.json.

Le bouton d'installation ne s'affiche pas

Certains navigateurs (Firefox, Safari sur ordinateur) ne proposent pas d'invite d'installation automatique, ou l'application est déjà installée. Utilisez les instructions manuelles de la section Installer hors-ligne.

L'application ne fonctionne pas hors-ligne après installation

Assurez-vous d'avoir ouvert wheel.html au moins une fois en étant connecté, pour que tous les fichiers soient mis en cache avant de couper le réseau.

Un service worker ne fonctionne pas en ouvrant un fichier directement (file://). Pour développer ou tester en local, servir le dossier via un petit serveur HTTP, par exemple npx serve .
